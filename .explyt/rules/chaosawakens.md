# Chaos Awakens: Project Guidelines/Rules

Chaos Awakens is a Minecraft mod acting as the spiritual successor to OreSpawn. It's a content-heavy all-rounder that 
aims to introduce all types of content. As such, it requires an incredibly robust backend to support it. 

- The project depends on Nexus API for multiloader and Mocha for Molang parsing (logic is still handled within CA itself).
- The project is a Minecraft mod based on the Multiloader project setup for 1.20.1 on Java 17.
- All backend systems are meticulously-written and rigorously-tested to ensure proper failsafes and mechanisms are in place for a seamless experience.
